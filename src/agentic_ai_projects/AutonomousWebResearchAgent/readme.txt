Autonomous Web-Research Agent

A system that:
    Accepts a complex query
    Searches the web
    Extracts information
    Summarises → Stores → Generates a final structured report

🔧 Key Capabilities
    Tool calling (search, browser)
    Planning & subtask decomposition
    Memory for multi-step reasoning
